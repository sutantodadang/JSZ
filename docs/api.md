# jsz API Reference

Embedding API reference for jsz, generated by reading `src/root.zig` directly.
For design rationale (why Values are pointer-boxed, why the GC is generational,
why bytecode is the only engine) see [architecture.md](architecture.md). For a
guided tutorial see [getting-started.md](getting-started.md) and
[EMBEDDING.md](EMBEDDING.md). For task-oriented snippets see
[cookbook.md](cookbook.md). For the CLI built on top of this API see
[cli.md](cli.md).

`zig build docs` also emits Zig's autodoc HTML into `zig-out/docs/` from the
same source comments — use that for a browsable, always-current view.

---

## API stability tiers

jsz has not reached 1.0. Two tiers apply, per the stability note at the top of
`src/root.zig`:

**STABLE** (frozen for 1.0, semver-governed once tagged):
`version`, `Isolate` (`init`/`deinit`/`newContext`), `Context` (`deinit`,
`eval`, `registerNativeFn`, `globalObject`, `getProperty`,
`makeNumber`/`makeString`/`makeBool`/`makeUndefined`/`makeNull`, `gc`,
`gcStats`, `setLimits`), `Value` (`toI32`/`toF64`/`toString`), the
result/option types (`EvalResult`, `Exception`, `ParseError`, `StackFrame`,
`GcStats`, `Limits`, `NativeFn`, `NativeResult`), and `valueToDisplayString`.

**EXPERIMENTAL** (may change or disappear before 1.0, not semver-governed):
bytecode snapshot (`compileSnapshot`/`evalSnapshot`/`snapshot`),
`dumpBytecode`, `sourceMap`, `debug`, the JIT surface (`JitMode`,
`JitProfile`, `IcProfile`, `setJitMode`, `setIcStats`, `lastJitProfile`,
`lastIcProfile`, `lastFrameHighWater`,
`installNativeCountLoop`/`installNativeAccumulateLoop` and their fn types),
`_regex`, `evalModule`, `module_loader`, `asyncDoneSignaled`,
`resetGlobalShapes`, `gcConfigure`, `gcPauses`, `gcGenCounts`, and
`setInterpMode`.

Everything below is annotated STABLE or EXPERIMENTAL inline.

## Memory model

Values are handles valid until the owning `Context` is destroyed. Strings
passed into jsz (`makeString`, `eval` source, `registerNativeFn` name) are
copied. Strings jsz returns (`Value.toString`, `valueToDisplayString`,
`Exception.message`) are **borrowed** — valid only until the next `eval` (or
`evalModule`/`evalSnapshot`) call on that `Context`. Copy them
(`allocator.dupe(u8, s)`) to retain past the next eval. Host function
registrations (`registerNativeFn`) live for the `Isolate`'s lifetime.

## Module constants and top-level types

| Name | Definition | Description |
|---|---|---|
| `version` | `"0.0.0-phase9-scaffold"` | Semantic version string. Pre-1.0; do not parse as semver yet. |
| `jit_build` | `bool` (from `build_options.jit_enabled`) | `true` when this binary was built with `-Djit=true` (Cranelift backend linked). |
| `JszError` | `error{ NotImplemented, OutOfMemory }` | Error set for all jsz operations. |

```zig
pub const JszError = error{ NotImplemented, OutOfMemory };
```

### `InterpMode`

```zig
pub const InterpMode = enum { bc };
```

Interpreter selector. `bc` (bytecode VM) is the only variant — jsz has no
tree-walking interpreter. The enum exists as a forward-compatible switch
point; `Context.setInterpMode` / CLI `--interp=bc` are effectively no-ops
today but keep call sites future-proof.

### `JitMode` (EXPERIMENTAL)

```zig
pub const JitMode = enum { off, count, experimental };
```

| Value | Meaning |
|---|---|
| `off` | No profiling. `noteBackedge` calls in the bytecode VM are zero-cost (JIT pointer is null). |
| `count` | Count PC hits and detect hot sites; do not attempt native compilation. Forces `interp_mode = .bc`. |
| `experimental` | Count hits, detect hot sites, and attempt native compilation of hot leaf functions and loop back-edges (Cranelift, behind `-Djit=true`). Forces `interp_mode = .bc`. |

### `JitProfile` (EXPERIMENTAL)

```zig
pub const JitProfile = struct {
    hot_sites: usize = 0,
    compiled: usize = 0,
    deopts: usize = 0,
    direct_calls: usize = 0,
};
```

Snapshot of JIT activity from the most recent bytecode-mode eval. All fields
`0` unless `setJitMode` was set to something other than `.off`.

### `IcProfile` (EXPERIMENTAL)

```zig
pub const IcProfile = struct {
    own_hits: u64 = 0,
    proto_hits: u64 = 0,
    misses: u64 = 0,
};
```

Inline-cache hit-rate counters from the most recent bytecode eval. All fields
`0` unless `setIcStats(true)` was called first.

### `NativeCountLoopFn` / `NativeAccumulateLoopFn` (EXPERIMENTAL)

Function-pointer types for Cranelift-compiled loop kernels installed via
`installNativeCountLoop` / `installNativeAccumulateLoop` (see below). Defined
in `src/jit/loop_jit.zig`; re-exported from `root.zig` for the CLI to use.

## `Value`

```zig
pub const Value = extern struct {
    bits: u64 = 0,
};
```

Opaque handle to a JS value — `bits` is a pointer to an internal `JsValue`
(pointer-boxed, not NaN-boxed). A zero-value `Value{}` is the sentinel jsz
returns from `make*`/`getProperty` on allocation failure or absent property;
it round-trips through `toF64`/`toString` but does not mean JS `undefined`
unless the underlying bits actually encode `undefined`.

| Method | Signature | Stability | Description |
|---|---|---|---|
| `toI32` | `(Value) i32` | STABLE | Coerce to a 32-bit integer. |
| `toF64` | `(Value) f64` | STABLE | Coerce to `f64`. |
| `toString` | `(Value) []const u8` | STABLE | Coerce to a string. Borrowed — see Memory model above. |

```zig
const g = ctx.globalObject();
const score = ctx.getProperty(g, "score");
std.debug.print("score = {d}\n", .{score.toF64()});
```

## `Exception`

```zig
pub const Exception = struct {
    value: Value,
    message: []const u8,
    stack: []const StackFrame,
};
```

| Field | Type | Description |
|---|---|---|
| `value` | `Value` | The thrown JS value. May be `Value{}` for host-level failures (e.g. out-of-memory) that have no JS value. |
| `message` | `[]const u8` | Borrowed — valid until the next `eval` call. |
| `stack` | `[]const StackFrame` | Borrowed stack frames; currently empty (`&[_]StackFrame{}`) for all paths through `eval`/`evalModule`/`evalSnapshot` in the public API. |

## `ParseError`

```zig
pub const ParseError = struct {
    message: []const u8,
    line: u32,
    column: u32,
};
```

A host-visible `SyntaxError` from parsing. `line`/`column` are 1-indexed.

## `EvalResult`

```zig
pub const EvalResult = union(enum) {
    ok: Value,
    exception: Exception,
    parse_error: ParseError,
};
```

Result of `Context.eval` / `evalModule` / `evalSnapshot`. **Never a Zig
error** — script-level failures (thrown exceptions, syntax errors) are values,
not `error{...}` returns. A Zig `error.OutOfMemory` from the underlying
allocator is mapped to `.exception` with `message = "out of memory"` rather
than propagated, so callers only need to switch on the three tags:

```zig
switch (ctx.eval(source, "<embed>")) {
    .ok => |v| useValue(v),
    .exception => |e| std.debug.print("JS threw: {s}\n", .{e.message}),
    .parse_error => |e| std.debug.print("syntax: {d}:{d}: {s}\n", .{ e.line, e.column, e.message }),
}
```

## `Limits`

```zig
pub const Limits = struct {
    mem_bytes: usize = 0,
    gas: u64 = 0,
    time_ms: u64 = 0,
};
```

Resource limits for untrusted execution. `0` means unlimited for each field.

| Field | Enforced in | Notes |
|---|---|---|
| `mem_bytes` | All interp modes | Caps live heap + arena bytes. |
| `gas` | Bytecode VM only | Caps executed bytecode instructions. Set `interp_mode = .bc` (the default and only mode) to rely on it. |
| `time_ms` | Bytecode VM only | Caps wall-clock execution time. |

Limit breaches always surface as `EvalResult.exception`, never a crash or
hang. See [cookbook.md](cookbook.md#cap-execution-with-resource-limits) for a
runnable example and `Context.setLimits` below.

## `NativeFn` / `NativeResult`

```zig
pub const NativeFn = *const fn (*Context, []const Value) NativeResult;

pub const NativeResult = union(enum) {
    ok: Value,
    throw: Value,
};
```

Signature for a host function callable from JS, and its return type. Return
`.throw` to raise a JS exception from the host side (surfaces to JS `catch`
and, if uncaught, as `EvalResult.exception`).

```zig
fn hostMultiply(ctx: *jsz.Context, args: []const jsz.Value) jsz.NativeResult {
    const a = if (args.len > 0) args[0].toF64() else 0;
    const b = if (args.len > 1) args[1].toF64() else 0;
    return .{ .ok = ctx.makeNumber(a * b) };
}
try ctx.registerNativeFn("multiply", hostMultiply);
// JS: multiply(6, 7) -> 42
```

## `valueToDisplayString`

```zig
pub fn valueToDisplayString(arena: std.mem.Allocator, v: Value) ![]const u8
```

Convert a `Value` to a display string (ECMAScript `ToString` semantics, used
by the CLI to print eval results). Handles `undefined`, `null`, booleans,
numbers, strings, bigints, functions (`function name() { [native code] }`),
arrays (`Array.prototype.toString`-style comma join of primitive elements),
plain objects (`[object Object]`), and symbols (`Symbol(description)`).
Allocates from `arena`; the returned slice is valid until the arena is freed.
Can return an allocator error.

## `dumpBytecode` (EXPERIMENTAL)

```zig
pub fn dumpBytecode(arena: std.mem.Allocator, source: []const u8, source_name: []const u8, writer: anytype) !void
```

Compile `source` to bytecode and disassemble it to `writer`. On a parse
error, writes `SyntaxError: <message> (line L:C)` instead and returns
normally (no error). Backs the CLI's `--dump-bytecode` flag.

## `sourceMap` (EXPERIMENTAL)

```zig
pub fn sourceMap(arena: std.mem.Allocator, source: []const u8, source_name: []const u8, writer: anytype) !void
```

Compile `source` and write a bytecode-to-source JSON source map to `writer`
(one entry per opcode, including nested function literals, mapping back to
source line/column). Backs the CLI's `--source-map` flag. See
`src/runtime/debugger.zig` for the map format.

## `debug` (EXPERIMENTAL)

```zig
pub const debug = @import("./runtime/debugger.zig");
```

Debugger and source-map surface. Key members:

| Member | Description |
|---|---|
| `DebugStop` | Struct describing a pause: `source_name`, `source_offset`, `function_name`, `pc`, plus reason. |
| `installHook(hook: DebugHook, ctx: ?*anyopaque) void` | Install a callback invoked when a `debugger;` statement executes in the bytecode VM. |
| `clearHook() void` | Remove the installed hook. |
| `offsetToLineCol(source, offset) SourcePosition` | Map a byte offset in `source` to a 1-indexed `{ line, column }`. |
| `writeSourceMap(writer, source, source_name, compiled_fn) !void` | Lower-level entry point used by `jsz.sourceMap`. |
| `DebugSession` | Stateful session type with `setBreakpoint`/`removeBreakpoint`/`listBreakpoints`/`cont`/`stepOver`/`stepInto`/`stepOut`/`pause`/`stackTrace`. |

This is the mechanism behind the CLI's `--debug` flag (see
[cli.md](cli.md#--debug)).

## `_regex` (EXPERIMENTAL)

```zig
pub const _regex = @import("./runtime/builtins/regexp.zig");
```

Internal regex engine, exposed only so the fuzz harness (`zig build fuzz`)
can drive the matcher directly. Not a stable API — the leading underscore is
intentional.

## `snapshot` (EXPERIMENTAL)

```zig
pub const snapshot = @import("./bytecode/snapshot.zig");
```

Bytecode snapshot (cache) serializer/deserializer module. Most embedders
should go through `Context.compileSnapshot`/`evalSnapshot` rather than this
module directly; it is exposed for advanced use (custom snapshot pipelines,
inspecting the on-disk format). Format: a magic header + version, followed by
a serialized `BcFunction` tree (code, line table, constants, IC tables,
nested child functions).

## `module_loader`

```zig
pub const module_loader = @import("./runtime/module.zig");
```

Milestone 16 (ESM) host filesystem module loader. `buildBundle(gpa, base_dir,
entry_id, entry_source)` discovers the relative-import dependency graph from
disk and wraps it as a `__modules__` registry the runtime `require()`
resolver links and evaluates. Used by the CLI's script loader (`main.zig`
`buildWrappedScript`) and the Test262 module-test path. Most embedders should
call `Context.evalModule` instead of using this directly; reach for it only
when building a custom multi-file module loader.

## `asyncDoneSignaled`

```zig
pub fn asyncDoneSignaled() bool
```

M16 TLA: whether the most recent eval signalled async-test completion via
`$DONE` (wired to `__jszAsyncDone__`/`__jszAsyncFail__`). A `[module,
async]`-style test that finished `.ok` without signalling never actually
completed (e.g. a hung promise or deadlocked async dependency) and should be
treated as a failure by harnesses that check this.

## `resetGlobalShapes`

```zig
pub fn resetGlobalShapes() void
```

Test-harness hook: frees the process-global hidden-class (shape) store and
resets it to empty. The shape transition graph is never freed during normal
operation; long-running harnesses that spawn many isolates in one process
(e.g. the Test262 runner) call this between isolates to avoid unbounded
(multi-GB) growth. **Safe only between fully-`deinit`'d isolates** — no live
object may reference a shape from the store being reset. Most embedders never
need this.

## `Isolate`

```zig
pub const Isolate = struct {
    allocator: std.mem.Allocator,
    _impl: ?*anyopaque = null,
};
```

The VM root object. Owns the heap, GC, atom table, and symbol registry.

| Method | Signature | Stability | Description |
|---|---|---|---|
| `init` | `(std.mem.Allocator) JszError!Isolate` | STABLE | Create an Isolate backed by `allocator`. Returns `JszError.OutOfMemory` on allocation failure. |
| `deinit` | `(*Isolate) void` | STABLE | Tear down the isolate and free all owned memory. Idempotent (checks `_impl != null`). |
| `newContext` | `(*Isolate) JszError!*Context` | STABLE | Allocate a new `Context` bound to this isolate. |

```zig
var iso = try jsz.Isolate.init(allocator);
defer iso.deinit();
var ctx = try iso.newContext();
defer ctx.deinit();
```

One `Isolate` can own multiple `Context`s; they share the heap, GC, and atom
table but each has independent globals, `interp_mode`, `jit_mode`, and
`limits`.

## `Context`

```zig
pub const Context = struct {
    _isolate: *Isolate,
    interp_mode: InterpMode = .bc,
    jit_mode: JitMode = .off,
    limits: Limits = .{},
    ic_stats: bool = false,
};
```

A JS execution context: owns the global object and intrinsics. Globals
persist across `eval` calls on the same `Context`.

### `deinit`

```zig
pub fn deinit(self: *Context) void
```
STABLE. Destroys the Context (frees it via the owning Isolate's allocator).
Does not tear down the Isolate.

### `eval`

```zig
pub fn eval(self: *Context, source: []const u8, source_name: []const u8) EvalResult
```
STABLE. Compile and run `source` as a script in this Context's global scope.
`source_name` is currently accepted but not threaded into error output from
this call path (see `Exception`/`ParseError` field notes above — messages do
not currently embed it). Internally applies the Context's `jit_mode`,
`ic_stats`, and `limits` before running. Returns `.exception` with message
`"out of memory"` if the underlying allocator fails rather than propagating a
Zig error.

### `evalModule` (EXPERIMENTAL)

```zig
pub fn evalModule(self: *Context, source: []const u8, source_name: []const u8) EvalResult
```
Milestone 16 (ESM), Phase 1: evaluate `source` as ES-module code. Module code
runs strict per spec (11.2.2); `import`/`export` is desugared onto the
CommonJS `require`/`exports` model internally. `source_name` is the module's
canonical specifier (used as the `ModuleRecord` id and source name). Same
`EvalResult` contract as `eval`.

```zig
const r = ctx.evalModule("export const x = 1 + 1;", "<mod>");
```

### `setInterpMode`

```zig
pub fn setInterpMode(self: *Context, m: InterpMode) void
```
Set the interpreter mode for subsequent `eval`/`evalModule` calls. Only `.bc`
exists today.

### `setLimits`

```zig
pub fn setLimits(self: *Context, l: Limits) void
```
STABLE. Set resource limits for subsequent evals — see `Limits` above.
Passing `.{}` resets to unlimited.

### `setJitMode` (EXPERIMENTAL)

```zig
pub fn setJitMode(self: *Context, m: JitMode) void
```
Phase 9: set the JIT profiling mode. `.count` and `.experimental` imply
bytecode interpretation.

### `setIcStats` (EXPERIMENTAL)

```zig
pub fn setIcStats(self: *Context, on: bool) void
```
Phase 11: enable inline-cache hit-rate instrumentation for the next eval.
Read the result with `lastIcProfile()`.

### `gc`

```zig
pub fn gc(self: *Context) GcStats
```
STABLE. Trigger a manual mark-sweep GC cycle. Returns cumulative heap stats
after the cycle (equivalent to calling `gcStats()` immediately after).

### `gcStats`

```zig
pub fn gcStats(self: *Context) GcStats
```
STABLE. Return current GC stats without triggering a collection.

### `gcConfigure` (EXPERIMENTAL)

```zig
pub fn gcConfigure(self: *Context, nursery_bytes: usize, major_period: usize, pause_log: bool) void
```
M19: tune the generational GC.

| Parameter | Meaning |
|---|---|
| `nursery_bytes` | Fixed nursery size — young bytes allowed between minor collections. |
| `major_period` | Minor collections between full majors. `0` makes every collection a major (classic non-generational mark-sweep), used for A/B perf comparison against the generational path. |
| `pause_log` | When `true`, record per-collection pause durations, readable via `gcPauses()`. |

### `gcPauses` (EXPERIMENTAL)

```zig
pub fn gcPauses(self: *Context) []const u64
```
M19: per-collection pause durations in nanoseconds, recorded since pause
logging was enabled via `gcConfigure(.., .., true)`.

### `gcGenCounts` (EXPERIMENTAL)

```zig
pub fn gcGenCounts(self: *Context) GcGenCounts
```
M19: `(minor, major)` collection counts — see `GcGenCounts` above.

### `lastFrameHighWater` (EXPERIMENTAL)

```zig
pub fn lastFrameHighWater(self: *Context) usize
```
Phase 8: call-frame depth high-water mark of the most recent bytecode-mode
eval. Mainly a test/inspection hook for proper tail calls: a strict
tail-recursive function keeps this `O(1)` regardless of recursion depth.

### `lastJitProfile` (EXPERIMENTAL)

```zig
pub fn lastJitProfile(self: *Context) JitProfile
```
Phase 9: JIT profile from the most recent bytecode-mode eval. All-zero unless
a `JitMode` other than `.off` was set via `setJitMode`.

### `lastIcProfile` (EXPERIMENTAL)

```zig
pub fn lastIcProfile(self: *Context) IcProfile
```
Phase 11: IC profile from the most recent bytecode eval. All-zero unless
`setIcStats(true)` was called first.

### `compileSnapshot` (EXPERIMENTAL)

```zig
pub fn compileSnapshot(self: *Context, out_allocator: std.mem.Allocator, source: []const u8) ![]u8
```
Phase 8: compile `source` to a sourceless bytecode image (snapshot). The
returned bytes are allocated with `out_allocator` and owned by the caller —
they outlive the Context and can be persisted to disk. Propagates allocator
errors as a Zig `error`.

### `evalSnapshot` (EXPERIMENTAL)

```zig
pub fn evalSnapshot(self: *Context, image: []const u8) EvalResult
```
Phase 8: restore a bytecode image (produced by `compileSnapshot`) and run it
in the bytecode VM against a fresh realm. Same `EvalResult` contract as
`eval`.

```zig
const image = try ctx.compileSnapshot(allocator, "1 + 2");
defer allocator.free(image);
// ... later, possibly in a different process ...
const r = ctx2.evalSnapshot(image);
```

### `registerNativeFn`

```zig
pub fn registerNativeFn(self: *Context, name: []const u8, func: NativeFn) JszError!void
```
STABLE. Register a host function as a global JS-callable function named
`name`. `name` is copied. Returns `JszError.OutOfMemory` on allocation
failure. The function is called via an internal trampoline that maps
`NativeResult.throw` to a pending JS exception.

### `globalObject`

```zig
pub fn globalObject(self: *Context) Value
```
STABLE. Return the global object as a `Value`. Returns `Value{}` if the
internal snapshot call fails.

### `makeNumber` / `makeString` / `makeBool` / `makeUndefined` / `makeNull`

```zig
pub fn makeNumber(self: *Context, n: f64) Value
pub fn makeString(self: *Context, s: []const u8) Value
pub fn makeBool(self: *Context, b: bool) Value
pub fn makeUndefined(self: *Context) Value
pub fn makeNull(self: *Context) Value
```
STABLE. Construct primitive `Value`s from the host side. `makeString` copies
`s`. Each returns `Value{}` on allocation failure (the sentinel — see the
`Value` section above).

### `getProperty`

```zig
pub fn getProperty(self: *Context, obj: Value, name: []const u8) Value
```
STABLE. Read an own-or-inherited property from an object `Value`. Returns
`Value{}` if `obj` is not an object or the property is absent — this is not
distinguishable from a property that holds `undefined` by return value alone;
check `typeof` in JS first if that distinction matters.

## Full example

```zig
const std = @import("std");
const jsz = @import("jsz");

pub fn main() !void {
    var iso = try jsz.Isolate.init(std.heap.page_allocator);
    defer iso.deinit();
    var ctx = try iso.newContext();
    defer ctx.deinit();

    switch (ctx.eval("1 + 2", "<script>")) {
        .ok => |v| std.debug.print("result = {d}\n", .{v.toF64()}), // 3
        .exception => |e| std.debug.print("threw: {s}\n", .{e.message}),
        .parse_error => |e| std.debug.print("syntax: {s}\n", .{e.message}),
    }
}
```
